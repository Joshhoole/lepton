# Changelog

## 0.6.1 — 2026-11-13

- **Gemini voices in the Audio node.** Two more speech models through a Kie.ai key, beside ElevenLabs: **Gemini 3.8 Flash · Speech** and **Gemini 3.8 Flash Lite · Speech**. 70 voices listed by what each suits, one voice or two in conversation (start a line with a voice's name and a colon), sounds in angle brackets acted (`<laugh>`, `<sigh>`, `<whispers>`), and a Temperature setting. A new Audio node starts on Gemini 3.8 Flash.
- **Hints.** Rest the pointer on a button or a setting and a small card says what it does, with a tip where one helps (Aspect: "Auto reads it from your prompt…"; Seed: "keep the seed and change one word…"). Every dock button, the zoom and selection controls, a node's ports, model, Run button, history and connected images, and some forty model settings (aspect, resolution, duration, batch, seed, the voice sliders…) have one; anything else that had a plain tooltip shows it in the same card. A card for something inside a node stands beside the node, so it never covers the next setting. The first card waits half a second; moving along a row then shows the next at once. **Settings → Hints** turns them off (kept per browser); the browser's plain tooltips return. New module `public/js/tips.js`: the words are two lists at the top of it.
- A run that Kie.ai fails with its catch-all "Internal Error, Please try again later." now says so plainly on the node: that it was Kie's failure, that the request itself was accepted, and to try again or use another model.
- **Safer and sturdier local server.** Found by an audit of the code before release. (1) One request with a broken `%` sequence in its address stopped the whole server; a bad request is now answered with an error and nothing more. (2) Files beside the `uploads` folder (the app's own source, and the job list in `.cache`) could be fetched through `/uploads/` with an encoded `../`; only `public/` and `uploads/` are served now, with no hidden files. Keys in `.lepton.json` were never reachable. (3) Lepton listens on this computer only, but any website open in the same browser could still make the browser send it requests, and so could have started generations or changed settings. The API now answers only its own page: requests that say they come from another site, or that are addressed to a host name other than localhost, are refused. (4) A request over the size limit cut the connection, which the page showed as "failed to fetch"; it is now refused with a message, and saving a project accepts boards up to 128 MB (was 8). (5) An upload with a very long file name failed; the name is shortened and keeps its ending.
- **Undo fixes.** Plugging a prompt into a Link in that feeds a Prompt batch made two undo steps, the second of which appeared to do nothing: the batch's list of prompts is worked out from what feeds it and is no longer a step of its own. And a text box that was hidden and shown again could be saved as if it had been dragged to that height, which pinned it there and stopped it growing with its text (and counted as an edit for undo); a height is now kept only when the corner is actually dragged.
- **Seedance 2.5 on Kie goes to 30 seconds.** The Kie entries for Seedance all carried the same length limit, 2 to 15 seconds, which was wrong for every one of them. Checked against Kie's documentation (2026-11-12): Seedance 2.5 makes 4 to 30 seconds, Seedance 2.0 and 2.0 Fast make 4 to 15, and Fast stops at 720p (1080p was offered and would have been refused). The Duration control now follows those limits. Seedance through Higgsfield was already right (2.5 to 30 seconds, 2.0 to 15), because those limits are read from Higgsfield's own documentation. The interface's saved copy of model settings is renewed so the change shows without pressing Refresh models; the server needs a restart, since the limits live in `providers/kie.js`.
- **Links in titles and notes.** A web address written or pasted into a title or a note (`https://…`, `http://…` or `www.…`) is underlined and can be clicked: the page opens in a new tab. A press on a link can still drag its node, and a double-click still edits the text (the page opens a quarter of a second after a single click, so a double-click does not open it too). While the text is being edited an address is plain text. Nothing is stored for a link: the text is kept exactly as written and the addresses are found each time it is drawn, so only http(s) pages can ever be linked, and a full stop, comma or closing bracket after an address is left out of it.
- **The pen draws over everything.** Drawings used to sit underneath the nodes, so a line across a node, a note or a title was hidden by it. The drawing sheet is now the top layer of the board, and with the pen (or the eraser, or the scissors) on, a press anywhere draws: over a node's text boxes, menus, sliders and buttons too, none of which react while the tool is on. Back in Select, everything under a drawing works as before, because the sheet never takes the pointer. Drawings belong to the board, not to the node under them: move the node and the drawing stays where it was drawn.
- Dragging a node while the cursor was still in another node's text box left the cursor there, so the next shortcut (`D`, `X`, `⌫`…) was typed into the text. Pressing a node now finishes the typing first.
- **Undo covers everything.** `⌘Z` used to put back moves, resizes, connections and pen strokes only. It now undoes any change to the board, and `⇧⌘Z` redoes it, 100 steps deep: adding and deleting nodes (a deleted node returns with its strands, its group and its results), typing in any node, note or title, every setting inside a node, renames, strand order, everything done to groups (make, ungroup, rename, colour, fold, resize, reorder), drawings, crop-in-place, the board's name and Clear board. A drag, a slider pull or a pen stroke is one step; typing is one step per pause; each new press starts a new step. A message names what was undone ("Undid deleting 2 nodes."). Generation output is deliberately left alone: results, history and status are never rolled back, a result that arrives while you work is not a step, and a run that finishes after its node was deleted is still there when the node is brought back. Deleting a result or a run and restoring a past run are undoable. History survives saving a project (file addresses that move into the project folder are followed) and starts fresh when another board is opened. `public/js/history.js` was rewritten: instead of each feature reporting what it did, the board is compared with how it last stood whenever it is saved, and the difference becomes the step, so new features are undoable without any code of their own. The per-feature recording (`recordMove`, `recordInk`, the `group:resized` event) is gone; `save()` now announces `change`, and takes a second argument for pan and zoom so moving the view costs nothing extra. Measured on a 300-node board: 1 ms to take a step, 3 ms to undo an edit, 190 ms to bring back all 300 nodes after deleting them.
- **Group tabs.** The Groups sidebar is replaced by a column of tabs down the left edge of the board, one per group, always in view. Click a tab to glide to its group and select it. Drag a tab up or down to reorder: the others slide out of its way as it passes, the tab settles into place when let go, and the order is saved with the board and its project (`⌥↑` / `⌥↓` move a focused tab). A new group's tab is added at the bottom; renaming, recolouring, folding or ungrouping on the board shows in the tabs at once (a rename used to reach the old list only after the next change). A column longer than the window scrolls, with its ends faded, and scrolls by itself while a tab is dragged near its top or bottom. The tabs move aside for an open sidebar. The Groups button in the dock and `G` now hide and show the column; the choice is kept per browser. New module `public/js/grouptabs.js`; `reorderGroups()` in `groups.js`.
- **Combine node.** Several texts in, one text out (`J`). Connect Prompt nodes, LLM outputs, a Prompt batch or a Link out's text and they are joined in the order listed, exactly as written: no model, nothing reworded. Pieces are reordered by dragging and disconnected with ×; the separator is a blank line, a new line, a space, a comma, nothing, or your own. The node shows the joined text with a count and a Copy button, follows its sources as they change, and can feed any prompt input, another Combine, or a Link in. At run time an LLM feeding it is run first if it has no output yet. New module `public/js/combine.js`.
- **Crop images.** A crop editor for any still picture on the board: the crop button on a Media node, "Crop" in the enlarged view, or "Crop image" in a Media or Image node's menu. Drag the frame's corners and edges, move it, or draw a new one; hold it to an aspect ratio; turn the picture a quarter or flip it; nudge with the arrow keys. **Add to board** saves the crop as a new Media node beside the source; **Replace** swaps a Media node's picture in place and keeps the original, which "Restore original image" in the node's menu brings back. Crops are cut from the full-size file at its own resolution, the original file is never changed, and transparency is kept. New module `public/js/crop.js`.
- **Group panels can be resized.** Drag any corner of a group's panel to make it larger than its nodes: room to grow into, or a frame around an area. Corner marks show while the pointer is over the panel. A panel cannot be made smaller than its nodes, and stretches if a node is dragged past its edge, so a node is never left outside its group. The size travels with the group when it is dragged or nudged, stays put when a single node moves inside it, follows snap to grid, is undone with `⌘Z`, and is saved with the board. Double-click a corner, or press the new **Fit** button in the group's bar, to return to fitting the nodes. Dropping a node anywhere inside a larger panel adds it to the group, as before.
- **Bars and buttons no longer sit on top of each other.** Three overlaps fixed. A note or title inside a group had its bar (sizes, colours, formatting) exactly where the group's label, colours, Collapse and Ungroup are; the bar is now lifted clear of any group label it would cover, at every zoom. Messages appeared in the bottom-left corner, on top of the dock's first buttons in all but the widest windows; they now appear in the middle just above the dock, and move aside for an open sidebar and the zoom buttons. And the dock, wider since the link buttons were added, reached the zoom buttons in windows between about 1120 and 1320 pixels wide; the zoom buttons now move up a row below 1320.
- **Link in and Link out: a connection without a strand.** Plug references (images, video, audio, prompts, any number of them) into a **Link in** (`K`) and name it; a **Link out** (`⇧K`) anywhere else on the board stands for everything in that link, with one output per kind of thing it holds. No line joins the two: a coloured dot pairs them, and each can jump to the other. The node downstream sees the real sources as if each had its own strand, so reference strips, `@` mentions, previews, costs and runs behave exactly as before and follow the source when it changes. Quick add lists a ready-made Link out for every link; a strand dropped on empty canvas offers "Add Link in" (from an output) or a Link out that carries that kind (from an input); a strand can be let go anywhere on a Link in. Links belong to one board, and a connection that would make a link feed itself is refused. New module `public/js/links.js`; the look-through lives in `incoming()` / `outgoing()` in `state.js`.
- **Titles are rich text.** A title can now have several lines (`Return` starts a new one; `Esc`, `⌘⏎` or a click elsewhere finishes) and formatting: bold, italic, underline, strike-through, a highlighter, bullet points and numbered lists, from new buttons in the bar above a selected title or the usual shortcuts. The buttons format the selected words while you are writing and the whole title otherwise; `- ` or `1. ` at the start of a line begins a list. Changing a title's size or colour no longer ends the edit. Plain text in a title is regular weight and bold is heavy (800), so a bold word stands out; existing titles stay bold all through, a step heavier than before. What is stored is a small, cleaned piece of HTML (`data.html`) limited to those formats, so a board file from someone else cannot carry anything else in through a title; `data.text` keeps the plain words.
- **Nodes pull into line as you drag.** A dragged node, selection or group that comes within 6 pixels of lining up with another node on screen (edges against edges, middles against middles) is pulled the rest of the way, and a thin amber line shows what it lined up with. Hold `⇧` to place freely. New module `public/js/snap.js`; nodes are measured once when a drag starts, so a move costs a few thousandths of a millisecond.
- **Snap to grid.** A magnet button beside the zoom buttons (or `⇧G`) makes dragged nodes land on the board's 24 px grid, and makes the arrow keys move by one grid square. The setting is kept per browser.
- **Titles no longer change size as you zoom.** A title used to be held at 15 px on screen when the board was zoomed far out, which made it grow against the nodes around it. It is now a fixed size on the board like everything else.
- Pressing a node that was not on top replayed its arrival animation (a short fade and a 6 px slide). It no longer does.
- **Double-click to edit works again.** Double-clicking a node's name, a title, a note's text, a group's label or a corner grip did nothing: pressing on a node captures the pointer for dragging, and the browser then delivers the double-click to the canvas instead of to what was clicked. The canvas now hands it back. A node's name can also be changed from its ⋯ menu (Rename); `Esc` cancels a rename, and `@` mentions and reference strips pick up the new name straight away. Double-clicking a note puts the cursor where you clicked. Pressing anywhere else on the board finishes the edit. The scissors and the pen do not open text.
- **Audio node: ElevenLabs speech through Kie.ai.** A new generator node (`A`, the dock, quick add, or drop a text strand on empty canvas) that turns text into speech with a Kie.ai key. Four models: **Multilingual v2** and **Turbo v2.5** (one voice; Turbo can be held to a language), **Dialogue v3** (several voices in one take: start a line with a voice name and a colon, and `[whispers]`-style directions are acted) and **Voice isolation** (a recording in, the voice alone out; the text box gives way to an Audio input). 67 voices, each with a sample you can play from the node; stability, similarity, style and speed are sliders (double-click one to reset it). Text comes from the node, a Prompt, an LLM, or a Prompt batch for one clip per prompt, up to 5,000 characters a run. Results are players in the node with a number to pick the output; the audio connects to Preview, LLM and Video models that take audio, and is kept in History, saved with projects and included in downloads like any other result.
- Model settings can now be sliders and can carry their own names for options (voices, languages), and a model can show a short note under its name.
- **Much faster on big boards.** Measured on a 161-node, 195-strand project with 199 pictures and 32 videos on a 120 Hz Mac: panning went from 9 frames a second to 120 at every zoom level, zooming from 2 or 3 to about 100, and dragging a node from about 2 to between 60 and 110. A board four times that size (648 nodes) pans at 40 to 80 and drags at about 40. What changed:
  - **Small copies of pictures.** The board shows a 720-pixel copy of each picture and keeps the original for generating, enlarging, comparing and downloading; that board was loading 392 megapixels of pictures to fill about 2. A picture switches to its original while it is zoomed in on or its node is pulled large. Copies are made in the browser the first time a file is seen and kept in `.cache/thumbs` (new server module `thumbs.js`); transparency is kept, and nothing is written into a project. The size shown under a Media node is still the original's.
  - **Videos are still frames until you point at them.** A clip shows its first frame and loads only while the pointer is over it; a few seconds after the pointer leaves it returns to the still and lets go of the file. A Media node shows a clip's size and length without loading it.
  - **Far away, nodes are simpler.** Below 30% zoom each node shows only its name, drawn larger, and its pictures. Nothing moves or changes size; notes and titles are unaffected.
  - The board was pinned as a single compositor layer (`will-change: transform`), which made the browser keep it as one huge picture and rescale it every frame.
  - Redrawing strands measured a port, changed a path, measured the next port and so on, which made the browser lay the whole board out again once per strand (340 ms for 195 strands; now 3 ms). Strands and ports that did not change are no longer touched, and a node's element is remembered instead of searched for.
  - The dot grid was the viewport's background, repainted on every pan step (a fifth-of-a-second stall about twice a second on a big board), and its fade below 40% zoom was a property every node inherited. It is now its own sheet, slid with a transform.
- **Large editor.** Hover any text box in a node (prompts, an LLM's system prompt, instruction and output) and an expand button appears in its top-right corner. It opens the same text in a big editor with a word and character count, Copy and Revert. The editor mirrors the box: every keystroke lands in the node and is saved as it is typed, `@` mentions work, and a result that arrives while it is open shows up in it. `Esc`, `⌘⏎`, Done or a click outside closes it.
- **Scrolling inside text boxes.** With the pointer over a text box that holds more than it shows, the wheel scrolls the text; before, it always moved the board. One scroll keeps doing what it started doing, so moving across the board does not stall when a text box passes under the pointer, and reaching the end of a text does not start dragging the board. `⌘` + scroll still zooms anywhere.
- **Canvas tools.** Three tools sit at the left end of the dock, and one stays on until you pick another or press Esc. **Select** is the normal mode. **Scissors** (`X`): drag a line across strands and every one it crosses is cut when you let go, or click a single strand; the strands about to go turn red as the line passes them, and `⌘Z` brings the whole cut back in one step. **Pen** (`D`): draw on the canvas itself in six colours and three thicknesses, with an eraser that removes a drawing when dragged over it and Clear all; strokes are saved with the board and with projects, and `⌘Z` undoes a stroke or an erase. Space or ⌥ still pans while a tool is on.
- **Notes, titles and a film layout.** For keeping pre-production on the same board as the generating. A **Note** (`N`, or Notes in the dock and quick add) is a coloured sticky note; lines that start with `[ ]` become checkboxes, and "To prompt" turns it into a Prompt node. A **Title** (`T`) is large text in four sizes that never drops below a readable size however far out you zoom. **Film layout** drops five labelled sections onto the board: References, Characters, Locations, Shots, Finals. Notes and titles have no ports and are never sent to a model; they move, group, copy and save like any node.
- **Draw on an image.** The pen button on a Media node (also "Draw on it" in the enlarged view, and in the right-click menu of Image nodes) opens the picture with a pen, an arrow, six colours and three thicknesses. "Add to board" saves the marked-up picture as a new Media node beside the original, ready to connect to a model as a reference that shows what you mean.
- **Tidy up.** Select two or more nodes and press Tidy up in the bar at the top (or the right-click menu) to straighten them into rows and columns without rearranging them: each node stays in the place it already holds. `⌘Z` puts them back.
- **Captions.** A Media node takes a one-line caption under the picture; the field appears when the node is selected.
- **New logo.** The Lepton glyph at the top left and in the browser tab is now the drawn mark (`public/logo.png`, `public/favicon.png`) instead of a typeset character.
- **Stop a run.** While a node is generating, its button becomes **Stop generating** (Stop on LLM nodes; also in the node's right-click menu). What happens depends on how far the run got, and the app says which: stopped before anything was sent (nothing spent); cancelled with the provider while it was still queued (Higgsfield and fal.ai allow this); or too late, because the provider has already started and the result will arrive as usual. Kie.ai, Google and OpenAI have no way to recall a job once it is sent, so with them only the first case can succeed. A text run that is stopped ignores the answer and keeps the earlier output. A run stopped in time ends quietly: no error on the node, and the results it showed before come back.
- **Run board is gone.** The Run button on the dock and its `⌘⏎` shortcut are removed; nodes are run one at a time from their own button or with `⏎`.
- **A tidier look.** Same dark, grey-on-black Lepton, with the loose ends tied to a few rules: seven type sizes instead of fourteen, six corner roles instead of twelve, control heights of 28, 32 and 36, sentence-case labels in place of small capitals, hint text you can actually read (contrast up from about 2.9:1 to 4.4:1), a ring on keyboard focus, quieter shadows with menus one shade lighter than nodes, a tick or exclamation mark on toasts so status does not rest on colour, and entrance animations that respect the system's Reduce Motion setting. Stylesheet only; nothing behaves differently.
- **Quick add, rebuilt.** `⇧A` opens it where the pointer is, and the node lands there. With nothing typed it shows categories (Text, Image, Video, Audio, View, Link, Notes, Skills); hover or arrow onto one for its list. Start typing and it searches everything at once, names first. Clicking elsewhere, scrolling the canvas or switching window puts it away, where before it stayed on screen. Uploads from it open the file picker already filtered to images, video or audio. `⌘K` still opens it.
- Fixed: quick-add rows overlapped when a skill had a long description. Skills whose description is written as a multi-line block in SKILL.md showed ">" instead of the text; they read properly now.
- **Storage.** A new Storage sheet (Settings → Manage storage…, or the button at the foot of the Projects sidebar) shows what Lepton keeps on disk, split into projects, temporary files, recently removed and archived, and how much can be cleared. "Free up space" clears everything that is safe to clear in one go.
  - **One copy, not two.** Saving a project used to leave the original of every file behind in `uploads/`. The project's copy is now a clone where the disk supports it (free on a Mac), and the temporary one is removed once the board points at the project's.
  - **Uploads is a temporary folder.** A file that no saved project and no open board has used for 14 days (7, 30 or never, your choice) moves to Recently removed. Each browser tells the server which files its board uses, so nothing on an unsaved board is ever cleared, and automatic clearing only starts three days after the first check-in.
  - **Trim history.** Per project: drop the earlier runs, or also the takes you did not pick (one result per prompt is kept). The sheet shows how much each frees before you choose.
  - **JPEG by default.** On save, PNG results are stored as high-quality JPEG, usually well under half the size. Pictures with transparency, 16-bit PNGs and files you add yourself are never changed. Switch to PNG under Image format to keep results exactly as returned; any project can still be converted by hand from its row.
  - **Archive.** Pack a finished project into one zip in `Archive/` inside the projects folder and take it off the list. "Finals only" keeps the board and one picked result per prompt. Restore brings it back as a normal project.
  - **Remove unused files** in a project: anything in its media folder the board no longer points to.
  - **Recently removed.** Everything above goes to a `.trash` folder first and stays for 30 days, with Restore on each batch (the board comes back too when the project has not been saved since) and Empty now. The exceptions are a temporary file a project already holds a copy of, and the files left out by a finals-only archive, which asks twice.
- Fixed: a Media node could be saved while its file was still uploading, which stored a temporary link that died with the page and left a broken image for good. Temporary links are no longer written to the browser store or to a project, and saving waits for uploads to finish. A node that already lost its file now says so and has a "Choose file…" button that puts a file back without touching its connections.
- A project folder that has been moved or renamed now opens with its media intact: the board's links are pointed at the folder's new place.

## 0.6.0 — 2026-11-07

- **Audio in, audio ports.** Dropping or pasting a WAV, MP3, M4A, OGG, AAC, FLAC or AIFF file makes an audio Media node (some audio files arrive with no type and were being ignored). Video models that take audio, such as Seedance 2.0 and 2.5 on Higgsfield and Kie.ai, show an "Audio refs" port; the clip is sent as the model's audio reference and gets an "A1" chip you can mention in the prompt.
- **Prompt batch → one generator.** The batch node has a single "All prompts" port in its header. Connect it to an Image or Video node and that one node runs every prompt at once with the same settings, one result per prompt (the Generate button shows ×N). Other text connected alongside goes in front of each prompt. The per-prompt ports are still there on each row.
- **Preview handles many results.** More than four items show as small numbered tiles; click one to look at it large with the rest in a strip underneath, and use the buttons to enlarge, pop it out as its own node, or download it.
- **Peek at what a strand carries.** Hover a connected-image chip, a linked prompt (or a row of a linked Prompt batch), or an input port with something plugged in, and a card beside the node shows the image or clip large, the full text, or the list of what is connected.
- **Reorder connected images.** Drag a chip along the row of connected images to change which is 1, 2, 3; the model receives them in that order and the @ tags in the prompt keep pointing at the same images.
- **Show in folder.** Every result thumbnail, Preview item, Media node and the enlarged view has a folder button that reveals the file in Finder (or Explorer), so there is no need to download what is already on disk. A result still sitting on the provider's server is saved first, into the open project's media folder or else the uploads folder, and the board switches to that copy.
- **Prompt length warning.** Kling models take at most 2,500 characters and answer anything longer with "The text length cannot exceed the maximum limit". Image and Video nodes on such a model show a counter under the prompt as it nears the cap, turn it red when over and say by how many characters to cut (with a Prompt batch connected, the longest prompt counts). Generate refuses before anything is spent, and a limit the provider reports itself (Higgsfield pages, fal schemas) is read the same way.
- **Pop a prompt out.** Hover a row in a Prompt batch and click the pop-out button to get that prompt as its own Prompt node, text already in place.
- Skills install from `.skill` files too (they are zip archives by another name): drop one on the canvas or pick it with Install…, same as a .zip.
- Fixed: clicking a result in a Preview with many items scrolled the canvas itself, so the camera jumped and the pointer no longer lined up with the board. Only the strip scrolls now, and the canvas undoes any stray browser scroll.
- Fixed: Kling 4.0 on Higgsfield failed with "image_url is a required property" when images were connected to References. The model page marks reference inputs as "Conditional", which the docs reader skipped, so the request went to image-to-video without a start frame. Conditional inputs are read now; an image-to-video endpoint given only references uses the first as its start frame; and a request missing a required input is refused with a message naming the port instead of the provider's error.
