Projects

A project is a folder with project.json and a media folder holding every file the board uses. Copy, back up or share the folder freely.

Skills

Installed skills live in your skills folder and stay there between sessions. Drop a .skill or .zip file, a SKILL.md or a folder onto the canvas to install one, or open the folder () and drag a skill folder in yourself.

ℓ  A blank board.
Add a node from the dock, drop images or video onto the canvas, or press ⇧A to add one where your pointer is.

Section

Settings

Connections

Add a key for each service you want to use. Keys are saved only in a file next to the app on this computer; the local server uses them to talk to each provider directly.

Projects folder

Where new projects are created and which folder the Projects sidebar lists. Projects elsewhere can still be opened by path.

Skills folder

One folder per installed skill, shared by every project. Skills are plain files, so you can edit them with any editor or copy them to another computer.

Storage

See what takes up space, clear temporary files, trim history, choose the image format and archive finished projects.

Hints

Explain buttons and settings when the pointer rests on them

Board

Clear the whole board? This cannot be undone.

The board autosaves in this browser. Files you drop in and new results wait in the uploads folder next to the app until a project is saved, which gives the project its own copy.
